## Evidence rule

**Listed, installable, detected, source-documented, smoke-tested, functionally checked, and device-verified are different states.** A source or package link does not prove the tool installs or works on every Android device. See [Compatibility and verification](Compatibility-and-Verification.md).

These versioned `wiki/` pages are maintained alongside the code as the reviewable documentation source. Changes must be published to the separate GitHub Wiki to make its pages match.
